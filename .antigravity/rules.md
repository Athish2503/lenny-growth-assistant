# Project Rules

Always follow these rules.

- Never change folder structure.
- Never rename existing classes.
- Never move files.
- Use dependency injection.
- Use SQLAlchemy ORM.
- Never access environment variables directly.
- Use Config class.
- Business logic belongs inside Services.
- Routes should only validate requests.
- Controllers coordinate.
- Services implement logic.
- Repositories handle database access.
- Retrieval layer must remain isolated.
- Providers must implement BaseProvider.
- Prefer composition over inheritance.
- Add docstrings and type hints.
- Never hardcode prompts.
- Keep functions under 50 lines where practical.
