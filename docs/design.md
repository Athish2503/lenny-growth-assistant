# Lenny Growth Assistant

# UI / UX Design Document

---

# Design Philosophy

The interface should resemble modern AI productivity
tools such as ChatGPT and Claude while remaining
focused on research and content generation.

The user should never feel overwhelmed.

The design should emphasize

- Simplicity
- Focus
- Transparency
- Fast interaction
- Minimal clicks

---

# Design Goals

The application should allow users to

Search

↓

Understand

↓

Generate

↓

Create

without leaving a single workspace.
